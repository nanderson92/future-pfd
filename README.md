# Future Systems Atlas

Edited static site files for the Future Systems Atlas portfolio project.

## Files
- `index.html` — page structure and project narrative
- `styles.css` — visual design, responsive layout, atlas cards, master stack, and interaction states
- `data.js` — preserved technology library, chemical spine, unit operations, bottlenecks, readiness data
- `app.js` — rendering, search, filters, cards, modals, and atlas interactions

## Run locally
Open `index.html` directly in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/`.
